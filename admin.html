Welcome, admin. Changes publish to the live site when you press Publish.

1 · GitHub access

Publishing writes to the website's GitHub repo. Paste a token once — it stays only in this browser (never on the website, never sent anywhere except GitHub).

How to make a token: GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Name it “Al-Noor Optics admin”. Repository access: Only select repositories → Usmankalera-dev/al-noor-optics. Permissions → Repository permissions → Contents: Read and write. Generate, copy the token, paste it above. Expiry 90 days is fine — make a new one when it expires.

2 · Frames

Add a frame, change its name or price, or remove it. New photos should be on a white background (JPG or PNG).

Add a new frame

Removed frames disappear from the live gallery. Their photo files stay in the repo — harmless.

3 · Shop details

These appear across the whole site — top bar, header, about, visit section and footer.

4 · Security — change admin password

Leave empty to keep the current password.

Honest note: this login is a basic gate, not bank-level security. It keeps casual visitors out, but anyone who reads the page code could work the password out — so pick a password you use nowhere else, and change the default after your first login.

5 · Publish

Publishing saves frames, prices and shop details to the live site. It takes about 2 minutes for the live site to update after publishing.

Bookings still arrive on WhatsApp — there is no booking inbox here, because the site does not store bookings anywhere.
